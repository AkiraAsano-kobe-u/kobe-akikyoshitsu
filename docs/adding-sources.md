# 時間割を追加する

このツールは、各学部・研究科が公開している時間割PDFの「教室」欄だけを読み、
「この曜日・クォーター・時限に、この教室で授業がある」という事実を集めます。
どのコマにも出てこない教室が、その時限の空き教室です。

## 1. source を書く

`sources/<学期>/<まとまり>.toml` に1PDFにつき1エントリを書きます。

```toml
[defaults]                 # このファイルの全 source に効く既定値
parser = "grid"            # src/akikyoshitsu/parsers/ のモジュール名
area = "工学部"            # 教室が属するエリア (下の「エリア」参照)
page = "https://..."       # PDFへのリンクが載っている公式ページ

[[source]]
id = "eng-aa"              # 全ファイルを通して一意。cache/<学期>/<id>.pdf になる
title = "工学部 建築学科 第3・4Q時間割表"
url = "https://....pdf"
```

教室名まわりの任意キー（`core.resolve_rooms` が解釈します）:

| キー | 意味 |
|---|---|
| `room_pattern` | 教室とみなす表記の正規表現（全体一致）。既定は `B210` `LR501` `C3-302` などの形 |
| `strip` | 教室名から取り除く部分の正規表現（例: 接頭辞 `^鶴1`） |
| `foreign` | `{エリア名 = 正規表現}`。他キャンパスの教室を指す表記をそのエリアに振り分ける |
| `rename` | `{正規表現 = 置換}`。表記ゆれを1つの教室名にそろえる |
| `quarters` | このPDFが扱うクォーター。既定は学期の全クォーター |

教室欄の文字列は先に NFKC 正規化されます（全角英数は半角に、ローマ数字「Ⅰ」は「I」になる）。
正規表現は正規化後の文字で書いてください。

`[defaults]` と `[[source]]` に同じキーがあれば source 側が優先です。`foreign` と `rename` だけは
表をキーごとに重ねます。

読めたコマが `min_slots`（既定 1）に届かない source があると build は失敗します。書式が変わって
読み落としたときに、その教室が黙って「空き」に見えるのを防ぐためです。本当にコマが無い時間割だけ
`min_slots = 0` と理由を書いてください。

教室と認識されなかった表記（「研究室」「遠隔」など）は捨てられ、`data/<学期>/report.json` の
`ignored_tokens` に残ります。本物の教室が捨てられていないか、必ずここを見てください。

## 2. エリアと教室名

エリアは「同じ教室名が同じ部屋を指す範囲」です。別キャンパスに同じ棟記号があるので
（鶴甲第1にも鶴甲第2にも B棟・C棟がある）、エリアを分けて衝突を避けます。

同じ部屋を複数の学部の時間割が別の書き方で指すことがあります（「本館102」と「Ⅰ-102」など）。
同じエリアの中では `rename` で1つの名前にそろえてください。そろえないと、片方の時間割でしか
使われていない時限が空きに見えます。

## 3. パーサ

パーサは `parse(path: Path, source: dict) -> list[Record]` を持つモジュールです。
`Record(day, quarter, period, token, evidence)` の `token` には教室欄の文字列をそのまま入れ、
正規化は `resolve_rooms` に任せます。

| パーサ | 書式 | 使っている時間割 |
|---|---|---|
| `grid` | 行が曜日（×クォーター）、列が時限で、各時限の右端に「教室」列がある罫線つきの表 | 工学部、システム情報学部 |
| `grid_star` | `grid` と同じ。★付きの教室を別キャンパスとして区別する | 国際人間科学部 グローバル文化学科 |
| `grid_ext` | `grid` の拡張。見出しの連結、6時限の行、白文字の除外、`period_map`、`extra` | 国際人間科学部3学科、人間発達環境学研究科、国際文化学研究科 |
| `hudev_course` | 1ページに4クォーターの表が縦に並ぶ | 人間発達環境学研究科 1年履修コース |
| `iphe_list` | 「月曜１限」の見出しの下に1行1科目が並ぶ一覧 | 全学共通授業科目 |
| `letters_grid` / `letters_kodokyoyo` / `letters_doctor` | 文学部の1枚物の表、高度教養の一覧、博士後期 | 文学部・人文学研究科 |
| `rk1_lawug` / `rk1_lawgr` / `rk1_econ` / `rk1_biz_ug` / `rk1_biz_gr` / `rk1_gsics` | 六甲台第1の各学部の表（共通部品は `_rokkodai1`） | 法・経済・経営・国際協力 |

共通部品: `_pdf`（語・罫線・行）、`_words`（教員名などと1語にくっついた教室名を切り離す。
格子型の表では必ずこれで語を取る）、`_ink`（紙面に見えない白文字の判定）。

前期・後期の通し科目は、該当する2つのクォーターの Record に展開します。
クォーターが読み取れないときは、両方のクォーターに入れてください。
**迷ったら「使用中」に倒す**のが原則です（空いていない教室を空きと表示するほうが害が大きい）。

## 4. 確かめる

```sh
uv run akikyoshitsu inspect 2026b <id> [-v]   # 1つの source を解析して表示 (data/ は書き換えない)
uv run pytest
uv run akikyoshitsu build 2026b               # data/2026b/ を作り直す
```

`inspect` の結果を、PDFを目で見た内容と少なくとも10コマ照合してください
（曜日・クォーター・時限・教室の4つとも）。照合したコマは `tests/` に固定値として残します。
PDFそのものはリポジトリに入れません（`cache/` は .gitignore 済み）。テストはキャッシュが
無ければ skip するように書きます。

## 学期を追加する

`sources/<学期>/` を作ります。学期の名前は「年度 + a(前期) / b(後期)」（例: `2027a`）。
`term.toml` にクォーターの期間を書きます（出典: 教養教育院の授業予定表）。時間割PDFのURLは
学期ごとに変わるので、各 toml の `page` に書いた公式ページから拾い直してください。
学期の途中でPDFが差し替えられたら、URLを更新して `akikyoshitsu build <学期> --refresh` し、
`git diff data/` で変わったコマを確認します。
