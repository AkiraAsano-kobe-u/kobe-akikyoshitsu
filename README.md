# 神大 空き教室

神戸大学の各学部・研究科が公開している時間割PDFの「教室」欄を読み、
**授業が入っていない教室**を曜日・時限ごとに割り出す非公式ツールです。

> [!IMPORTANT]
> 神戸大学が運営・保証するものではありません。分かるのは「時間割上その時限に授業が無い」ことだけです。
> 補講・試験・集中講義・課外活動・会議・施錠は反映されません。教室の利用可否は各学部のルールに従ってください。

## 対象（2026年度後期）

| エリア | 出典の時間割 |
|---|---|
| 六甲台第1 | 法学部・法学研究科・法科大学院、経済学部・経済学研究科、経営学部・経営学研究科、国際協力研究科 |
| 文学部 | 文学部、人文学研究科（博士前期）、文学部開講の高度教養科目 |
| 工学部 | 工学部6学科、工学研究科（博士前期）、システム情報学部、システム情報学専攻（博士前期） |
| 鶴甲第1 | 全学共通授業科目（教養教育院）、国際人間科学部（★の無い教室）、国際文化学研究科 |
| 鶴甲第2 | 国際人間科学部（★付きの教室）、人間発達環境学研究科 |

出典PDFのURLは `sources/2026b/*.toml`、生成済みデータは `data/2026b/occupancy.json` にあります。

### 分からないこと

- 時間割に一度も出てこない部屋は一覧に出ません。
- 理学部・農学部・医学部・海事科学部の時間割は読んでいません。これらが上のエリアの教室を使う授業は反映されません。
- 集中講義、MBA、曜日・時限が決まっていない科目は読んでいません。
- 時間割PDFの公開後に出た教室変更は、原則として反映されません。
- 大学院の夜間の時限（17:50〜19:20 など）は、重なる5限と6限の両方を「授業あり」としています。
- クォーターが読み取れない科目は、第3・第4クォーターの両方で「授業あり」としています。

## 使う

リポジトリを clone して、その中で実行します（`data/` と `sources/` を読むため）。

```sh
uv sync
uv run akikyoshitsu free              # いまの時限
uv run akikyoshitsu free 水 3 3Q      # 水曜3限・第3クォーター
uv run akikyoshitsu free 月 2 --area 鶴甲第1
uv run akikyoshitsu room LR501        # その教室で授業がある時限
uv run akikyoshitsu html              # site/index.html (データ埋め込みの1ファイルのWebページ)
```

## データを作り直す

```sh
uv run akikyoshitsu build 2026b            # PDFを取得 (cache/) して data/2026b/ を再生成
uv run akikyoshitsu build 2026b --refresh  # PDFも取り直す
uv run pytest
```

`data/2026b/report.json` に、教室と認識せず捨てた表記と、各コマの根拠になった時間割が残ります。

時間割PDFそのものは再配布していません（`cache/` は .gitignore）。PDFを読むテストは、キャッシュが無ければ skip されます。

## 時間割・学期を追加する

[docs/adding-sources.md](docs/adding-sources.md) を読んでください。新しい学期は `sources/<学期>/` を作り、
`term.toml` と各学部の toml を置きます。PDFの書式が変わっていればパーサの修正が必要です。

誤りを見つけたら、曜日・時限・教室と、時間割PDFの該当箇所を添えて Issue をお願いします。
